# 狼羊棋 · 网页版（人机对战）

5×5 人机对战的浏览器版本：**左侧棋盘 + 右侧对局信息**，点选走棋、快捷键操作。
棋盘与棋子全部用 CSS 绘制（圆形棋子：粗楷「狼」红字 /「羊」黑字），**不加载任何图片素材**；
棋盘元素只建一次、走棋后按格原地增量更新，不做整盘重绘，操作流畅不闪烁。

逻辑与求解引擎（`hard_solve_fast.py` + 表库 + DQN）一致：

- 选择执狼或执羊；**你执哪方，哪方棋子显示在最上一排**；狼方先行。
- 羊数 > 当前已解出的最大 k（现为 15）→ DQN 模型（`checkpoints/rv14/best_selfplay_dqn.pt`）；
  否则 → 硬解表库（`data/tb_test`，启动时自动扫描已完成的桶）最优应手。
- **节奏**：你走完一步后，模型**隔 1 秒**再应手（期间显示“模型思考中”）。

## 运行（SSH 开发场景，端口转发玩）

```bash
cd <仓库目录>
python3 web/server.py --port 8080        # 仅监听 127.0.0.1
```

本机浏览器访问（端口转发）：

```bash
ssh -L 8080:127.0.0.1:8080 <用户>@<服务器>
# 打开 http://127.0.0.1:8080
```

## 界面与操作

- 开局先点「狼 / 羊」选择阵营。
- **左列**：棋盘（翻转视角即你执狼时狼在最上排）、状态行、悔棋/换边/重开按钮。
- **右列**：
  - **局面分析**：当前回合一方的多条候选最优续着——羊数≤10 列出表库结论
    （如 `狼胜·最快9步`），>10 列出 DQN 前 N 候选（含 Q 值）；顶部是整局最优解。
  - **对局记录**：玩家/模型每一步的走子（含吃子）与走完后局面的结论。
- 走棋：点自己的棋子 → 落点绿色高亮 → 再点落点。
- 快捷键：`u` 悔棋 · `s` 换边 · `r` 重开。
- 错误提示会显示在棋盘下方，并自动与服务端重新同步局面。

## 依赖

- Python 3.10+（纯标准库 HTTP 服务）。
- `torch`（DQN 推理）：`pip3 install torch`（国内镜像：
  `pip3 config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`）。
- 表库文件由 mmap 只读加载，启动即用。
- 首次模型走棋加载权重约 1~3 秒，之后每步 < 0.1 秒。

## 代码结构

| 文件 | 作用 |
|---|---|
| `web/server.py` | 后端：对局、DQN/表库引擎、`POST /api`（choose/move/advance/undo/switch/restart/state） |
| `web/index.html` | 前端：CSS 棋盘/棋子、点选交互、原地增量渲染、1 秒延迟应手、右侧分析面板 |
| `wolves_eat_sheep_game/ai_engine.py` | DQN 推理助手（网页版复用其函数） |
