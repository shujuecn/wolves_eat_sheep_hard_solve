# 狼羊棋 · 网页版使用说明

本文档说明 Web 版的启动方式与全部操作。功能总览与实现说明见
[web/README.md](README.md)。

## 1. 启动服务

在仓库根目录运行：

```bash
python3 web/server.py --port 8080        # 默认即 127.0.0.1:8080
```

可选参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--port` | `8080` | 监听端口 |
| `--host` | `127.0.0.1` | 监听地址 |
| `--data-dir` | `data/ws_tb_dtc_260819` | 硬解表库目录 |

启动日志（已规范化）：

```
[狼羊棋·web] 启动 (pid 12345)
  监听  http://127.0.0.1:8080
  表库  …/data/ws_tb_dtc_260819 (k ≤ 15，含开局局面)
  引擎  tablebase 最优解
  停止  Ctrl-C
```

`Ctrl-C` 退出（打印 `[狼羊棋·web] 已停止`）。

## 2. 打开页面与选择阵营

浏览器访问 `http://127.0.0.1:8080`。开局**必须先点「狼」或「羊」选择阵营**
（执狼：狼在最上排并自动翻转为己方视角；执羊反之）。选择后模型开始自动应手。

## 3. 基本对局操作

**走棋有三种方式（任意时刻都可用）**：

1. 棋盘上点自己的棋子 → 落点绿色高亮 → 再点落点；
2. **直接点右侧「局面分析」里的某条候选最优解**：轮到玩家时走玩家自己的子，
   轮到模型时替模型走棋；
3. 手动模式下，棋盘上直接点**模型方**的棋子替它走。

棋盘下方按钮：**悔棋**（`u`）· **换边**（`s`）· **重开**（`r`）。错误提示显示在
棋盘下方，并自动与服务端重新同步。

## 4. 模式

| 模式 | 说明 |
|---|---|
| **自动 / 手动** | 自动（默认）：模型隔 1 秒自动应手；手动：模型不自动走，但仍可点候选框替它走，或直接点模型棋子。 |
| **无尽模式** | 棋盘下方勾选框，解除 150 步上限；若已因 150 步判和，勾选后自动解除终局继续下。 |
| **自由移动（摆子）** | 专为快速摆残局：狼可跳任意位置（或跳羊格吃羊）、羊可移任意空地。开启时**自动切为手动且期间无法切回自动**（按钮置灰+服务端拒绝）；关闭后保持手动，可自行切回自动。开启期间不提供最优解更新、模型不应手；关闭后按当前局面恢复标准规则。 |

## 5. 局面分析与最优解

- **局面分析**（右侧）：显示当前回合方的表库结论（如 `狼胜·最快9步`）与
  **全部**候选最优续着，按有利程度与最快步数排序（过长可滚动）。
- **鼠标悬浮**候选框某条最优解时，棋盘就地预览：金色虚线环=待移动的子、
  绿色落点=目的地、红色高亮=可被吃掉的子。
- **模型选步**：只在表库最优档选步（必胜最快/必败拖延/和棋），同档内优先选不
  回到已出现局面的走法（防 5 次重复判和），其余等价走法随机。
- **开局库**：开局前 6 个半回合（狼先行第 1～3 手、羊第 1～3 手），模型按
  `opening_book.json` 定点走棋（不随机摇摆）：有胜棋走最快胜、必败走拖延最长、
  和棋保和——例如狼在初始局面必走 `(4,2)→(2,2)` 中路跳吃保和；日志标记
  `（开局库）`。6 个半回合后恢复“最优档 + 防重复 + 随机”选步。

## 6. 一键导出最优棋谱

位置：**局面分析区右上角「导出最优棋谱」**按钮。

1. 点击弹出**确认页**（此时对局已暂停）：提示先走方固定为**当前轮到方**
   （视角随 Web 端，不可切换），可选：
   - **目标**：狼胜 / 羊胜 / 和棋（随先走方自动约束不可达项）；
   - **导出条数**：1～10，默认 1；
   - **步数起点**：从当前步数计 / 从 1 计；
   - **最大步数**：150（默认）/ 160——实际总步数超过上限的最优解不进棋谱；
2. 点「确认」后进入**锁屏计算**：进度条 + 百分比 + 耗时（秒，2 位小数）；
   期间对局暂停、禁止任何操作（服务端同步加锁），耗时较长；
3. 完成后展示结果面板：每张棋谱为**高清大尺寸 PNG 预览**（5 列多行棋盘子图，
   金=待走子、绿=落点、红=被吃子；PNG 头部一行「目标 · 全程实际总步数 · 先走方」），
   可逐张下载（文件名带 8 位数字+英文唯一编码，避免重名）；关闭面板自动恢复对局。

**导出语义**：棋谱不假设对手犯错——对手每步走表库最强防守（最长拖延、绝不送分），
导出的是官方规则下可合法完成的**最长强制线（赢或和棋）**，全程需步步精确。
导出完全只读，不改动当前局面。

**常见报错**：

| 提示 | 含义与处理 |
|---|---|
| `目标「狼胜」不可达成，可改选「和棋」` | 当前视角下结论不是狼胜，换一个可达目标。 |
| `当前视角已必败，无法生成最优棋谱` | 轮到方必败（无赢/和棋谱），只能换边或重开。 |
| `所有最优解实际总步数均超过设定上限 X 步…` | 调大最大步数（或开启无尽模式后 160 仍不够需调大）。 |
| `自由移动模式下不提供棋谱导出` | 先关闭自由移动再导出。 |

## 7. 对局记录与自动存档

- **对局记录**：玩家/模型每步的走子（含吃子）与走完后局面结论；步来源标记：
  `最优解` / `玩家自选` / `自由移动`。
- **自动存档**：每局结束或手动重开时，自动保存为
  `data/saved_games/game_YYYYMMDD_HHMMSS_*.json`（每步走子/吃子/表库结论 + 终局
  FEN）；记录面板实时显示“已自动保存 N 局”。

## 8. 常见问题

- **模型不动了？** 查看是否处于手动模式、或有错误提示；自由移动期间模型本就不应手。
- **自由移动后切不回自动？** 需先关闭自由移动，再切自动。
- **导出按钮置灰？** 对局已结束 / 未选阵营 / 自由移动中 / 导出计算中 / 结果面板打开时。
- **提示「表库 k=16 未求解」？** 仅当局面超出表库覆盖（k>15）时出现；标准开局羊数
  15，整局在覆盖内。
