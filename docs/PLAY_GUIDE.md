# 狼羊棋 · 终端版玩家指南

本指南说明如何**启动**和**游玩**本仓库里的 C++ 终端版狼羊棋（5×5，狼 3 只 vs 羊，狼先行）。
它用字符界面复刻了 `wolves_eat_sheep_game/` 里 Python 版 pygame GUI 的双人对局，
规则完全一致；另外附赠一个表库解棋器（`solve_term`），可以边玩边学最优下法。

---

## 1. 两个程序，各是什么

| 命令 | 作用 | 说明 |
|---|---|---|
| `./build/play` | **双人游戏** | C++ 复刻 Python GUI 的「双人(A)」模式：两名玩家轮流在同一个终端走棋 |
| `./build/solve_term` | **解棋器 / 陪练** | 读出已求解表库，给出局面结论、★最优应手、完整最优路线，并对你的每步棋点评 |

> 注意：`play` 是纯双人游戏（没有 AI）；想和"最强对手"下棋，用 `solve_term` 的
> `play` 命令（表库自动应手）。

## 2. 启动前：先构建（只需一次）

### 本仓库这台设备（无 make/apt，用 /tmp/gcc-local 的 g++）

```bash
export LD_LIBRARY_PATH=/tmp/gcc-local/usr/lib/x86_64-linux-gnu:$LD_LIBRARY_PATH
CXX=/tmp/gcc-local/usr/bin/g++
CXXFLAGS="-std=c++20 -O3 -march=native -flto -idirafter /tmp/gcc-local/usr/include -idirafter /tmp/gcc-local/usr/include/x86_64-linux-gnu"
LDFLAGS="-flto -L/tmp/gcc-local/usr/lib/x86_64-linux-gnu -Wl,-rpath,/tmp/gcc-local/usr/lib/x86_64-linux-gnu"

# 双人游戏
$CXX $CXXFLAGS -Iinclude tools/play.cpp build/board.o $LDFLAGS -o build/play

# 解棋器（多链几个目标文件）
$CXX $CXXFLAGS -Iinclude tools/solve_term.cpp \
    build/board.o build/encode.o build/symmetry.o build/tablebase.o \
    $LDFLAGS -o build/solve_term
```

### 一般机器（有 make）

```bash
make play          # 启动双人游戏
make solve-term    # 启动解棋器
```

## 4. 怎么玩

### 4.1 读棋盘

- **`W`（红色）= 狼**，**`S`（青色）= 羊**，`·` = 空位
- 坐标：**列 a~e，行 1~5**，`a1` 在左上角；开局狼在下方第 5 行 b/c/d 列
- 底部一行是**状态栏**：`狼方回合（红狼行动）第 N 步` / `羊方回合（黑羊行动）`，以及终局原因

### 4.2 走子（两种方式，任选）

**方式一：直接输入起止两格**（最快，推荐）

```
b5 b3
```

表示把 b5 的棋子走到 b3。

**方式二：先点选，再点目标（模拟鼠标）**

1. 输入一个格名（如 `c5`）→ 该棋子被选中（反白显示），**合法落点金色高亮**
2. 输入目标格（如 `c4`）→ 落子

### 4.3 取消选中

- 再点一次同一个棋子
- 点一个空格
- 点对方的棋子

都会取消选中（并提示）。

### 4.4 命令一览

| 输入 | 作用 |
|---|---|
| `u` | **悔棋**（可连续按，悔多步） |
| `r` | **旋转棋盘 180°**（和 Python GUI 的旋转按钮一样，方便对坐的玩家） |
| `b` | 重绘棋盘 |
| `h` | 帮助 |
| `q` | 退出 |

### 4.5 常见输入错误提示

- `（非法走法：c5 → c5）`：起止是同一格
- `（不是当前回合方的棋子）`：轮到羊走时点了狼（或反之）
- `（该格无棋子）`：起格是空的
- `（非法走法）`：目标不合法（只能上下左右一步，或按规则吃子）

## 5. 规则速查（与 Python 版完全一致）

1. **狼先行**，双方轮流，每回合只能动一个棋子，上下左右走**一格**
2. **吃子**：狼可以跳过**紧邻的一个空格**，落到两格外的羊身上（`b5` → 跳过空的 `b4` → 吃掉 `b3` 的羊）。每回合最多吃一只，吃完立即轮到羊
3. **狼胜**：羊被吃到不足 4 只
4. **羊胜**：三只狼全部无法移动（被围死）
5. **平局**：双方合计走了 150 步；或双方同一棋子连续往返 ≥ 5 次

## 7. 进阶：用解棋器边玩边学（`./build/solve_term`）

想研究局面、和"表库最强"对练、复盘自己的棋，启动解棋器：

```bash
./build/solve_term                 # 默认读 data/tb_test 已求解表库
./build/solve_term --preset 3      # 直接进入某个练习局面
```

启动后它会显示当前已求解的 k 值（如 `k=4,5,6,7,8,9`；k=10..15 求解完成后自动可用）。

常用命令：

| 输入 | 作用 |
|---|---|
| `load 0` / `list` | 载入练习预设 / 查看全部预设 |
| `ai` 或 `best` | 列出当前方**所有走法**的结局与步数，★ 标出最优应手 |
| `play` | **表库替你走**最优应手（人机对练） |
| `m a1 b2` | 手动走子（复盘时双方轮流输入），**自动点评**：`此步为最优` / `错失胜机` / `妙手逆转`… |
| `pv 20` | 打印双方都最优的**完整路线**（含每步剩余步数） |
| `setup www1s/ss1ss/1s3/5/5 s 0` | 摆任意局面（FEN）后立即给结论 |
| `undo` / `pos` / `rot` | 悔棋 / 打印当前 FEN / 旋转显示 |

示例（k=6 一个羊方必胜局面）：

```
表库结论: 羊胜（最快 9 步）
所有走法评估（羊方）:
  ★ e1→d1  → 羊胜（最快 8 步） ← 最优
    b3→a3  → 和棋
    b3→c3  → 狼胜（最快 43 步）
  结论: 羊方可强制获胜
```

> 步数是"半回合"：双方各走一手算 2。"最快 N 步"= 从现在起 N 步内（含）见分晓。

三种练习方式：

1. **人机对练**：自己 `m` 走，让表库 `play` 应手（或用 `--auto` 开局即全自动对弈）
2. **复盘点评**：双方轮流 `m`，每步机器都会告诉你是否最优、优劣变化
3. **摆盘研究**：`setup`/`load` 任意局面 → `ai` 看结论 → `pv` 看最优路线

## 8. 常见问题（FAQ）

**Q：画面颜色乱七八糟 / 全是转义符？**
A：改用 `./build/play --no-color`（或解棋器同样加 `--no-color`）。

**Q：怎么知道轮到我（另一名玩家）走？**
A：看状态栏。`狼方回合（红狼行动）` 红狼走；`羊方回合（黑羊行动）` 黑羊走。
对坐玩时用 `r` 旋转棋盘。

**Q：吃子怎么操作？**
A：和普通走子一样输入起止两格，例如 `b5 b3`（中间必须隔一个空位，目标格必须是羊）。
程序会自动判定，吃子会在落点显示并提示。

**Q：走错了怎么办？**
A：`u` 悔棋，可连续悔多步（直到开局）。

**Q：`h` 帮助太长没看完？**
A：随时再输入 `h` 即可重看；`b` 只重绘棋盘。

**Q：和 Python 版有什么不同？**
A：规则完全相同；Python GUI 的「双人(A)」= `play`；「玩家 vs 模型 / 模型对局 / 回放」
由 `solve_term` 的表库对练与复盘功能覆盖。终端版没有音效和图片，但多了**每步点评与最优路线**。

**Q：解棋器说"未求解"？**
A：该 k 值（羊数）的表库还没算完或在更高桶。`m` 仍可正常走子；等 `solve_retro` 产出该桶后
重启（或输入 `refresh`）即可获得结论。
